These are the blocks that ship with Makecord. This page is generated from the blocks themselves, so it always matches the version you're reading about.

Any text setting can contain [variables](/docs/variables/).

Messages the bot sends can ping the people they mention, like `{{user.mention}}`, but not @everyone, @here or roles. That keeps a member, or an AI answer, from pinging the whole server through text the bot repeats. To let one message ping them, turn on **Let this message ping @everyone and roles** on **Reply**, **Send Message** or **Reply to Message**.
