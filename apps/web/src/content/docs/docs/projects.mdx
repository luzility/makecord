A Makecord project is a plain folder. Nothing lives in a database, so you can version it with git, review changes and copy it anywhere.

```txt
my-bot/
├── makecord.json          # name, intents, plugins, secret names, cache limits
├── commands/
│   ├── ping.flow.json     # one file per slash command
│   └── greet.flow.json
├── events/
│   └── ready.flow.json    # one file per event flow
├── functions/             # flows that other flows call
├── messages/              # message designs
├── package.json           # "start": "makecord start ."
├── Dockerfile
├── docker-compose.yml
├── .env.example           # DISCORD_TOKEN= (no value)
├── .gitignore
└── .makecord/             # IDE state: open tabs, layout (gitignored)
```

Flow files can live in any folder. The runtime loads every `*.flow.json` in the project except inside `node_modules` and hidden folders. `commands/` and `events/` are only a convention.

## Templates

**New project** starts from a template:

| Template | What you get |
| --- | --- |
| Starter | `/ping`, `/greet` and a log line when the bot is ready |
| Welcome messages | A designed welcome message in the server's system channel, a welcome DM and a goodbye |
| Moderation | `/ban`, `/kick`, `/timeout`, `/purge`, and `/warn` with a warning count per member |
| Support tickets | A panel with a button that opens a private channel per ticket, and a button to close it. Paste your staff role ID into the **Set Variable** block of the ticket flow, or only admins can see tickets |
| Levels | 1 XP per message (at most once every 30 seconds), a level up every 25 XP and `/rank` |
| AI assistant | Answers when mentioned and remembers each channel, plus `/ask`. Both can call two functions, and both have a 15 second cooldown per member. Needs an [AI](/docs/ai/) key |

Templates add the intents and plugins they need to `makecord.json`. Some intents, like `GuildMembers` and `MessageContent`, also have to be turned on in the Developer Portal.

## Finding things

- **Search everywhere** (**Ctrl+K**, or **Shift** twice) finds files and actions.
- **Find in files** (**Ctrl+Shift+F**) searches the text of every file. In flows it searches block settings and opens the block it found.
- **Recent files** (**Ctrl+E**) switches to a file you had open. **Ctrl+Tab** and **Ctrl+Shift+Tab** move between tabs, and **Ctrl+W** closes one.

## makecord.json

The project's settings. Every field is listed in the [project config reference](/docs/project-config/). The ones you'll touch most:

- `intents` decides which events Discord sends the bot. Some events need an intent, and the Problems panel tells you which one is missing.
- `devGuildId` registers commands to one server while you develop.
- `plugins` lists extra block packages to load.
- `secrets` names the secrets the bot expects. Values never go in this file.

Changes to `makecord.json` take effect the next time you press Run.

## When a file is broken

A flow file with invalid JSON or an unknown shape doesn't take the bot down. The runtime skips that file, reports it in the Run panel and the Problems panel, and runs everything else.
