# Interface fonts

Rondel, Beacon, Cove, Aurelia, Halden, Alder, Tessera and Mallow are from [fontzz](https://github.com/Luffixos/fontzz), licensed under the SIL Open Font License 1.1. Each folder keeps its own `OFL.txt`, which must ship with the font.

Geist and JetBrains Mono come from `@fontsource-variable/*` (also OFL 1.1).
