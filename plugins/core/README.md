# @makecord/plugin-core

The built-in blocks of [Makecord](https://makecord.luzili.tech): replies, messages, roles, moderation, channels, threads, polls, forms, logic, HTTP requests, storage and more. The runtime loads it automatically, so projects don't need to install it.

The [block reference](https://makecord.luzili.tech/docs/blocks/) lists every block and its settings.
